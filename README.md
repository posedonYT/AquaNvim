# 🌊 AquaNvim

```
┏━┓┏━┓╻ ╻┏━┓┏┓╻╻ ╻╻┏┳┓
┣━┫┃┓┃┃ ┃┣━┫┃┗┫┃┏┛┃┃┃┃      dive deep · code clear
╹ ╹┗┻┛┗━┛╹ ╹╹ ╹┗┛ ╹╹ ╹
```

Дистрибутив Neovim в водной тематике с собственной цветовой палитрой **Aqua**,
включаемыми **Extras** (языки и плагины, как в LazyVim Extras), **сессиями** для каждого проекта
собственным **AI-харнесом для локальной нейросети** (**Aqua AI**: файлы, папки, Markdown, интернет)
и интеграцией с **Claude CLI**.

Требуется **Neovim ≥ 0.11**, `git`, [Nerd Font](https://www.nerdfonts.com/), `ripgrep`;
опционально: `lazygit`, `fd`, [`claude`](https://docs.anthropic.com/en/docs/claude-code),
[Ollama](https://ollama.com) (или другой сервер локальных моделей) для Aqua AI.

## Установка

### ❓ Сделайте резервную копию текущего конфига (если он есть)

```bash
mv ~/.config/nvim ~/.config/nvim.bak
mv ~/.local/share/nvim ~/.local/share/nvim.bak
mv ~/.local/state/nvim ~/.local/state/nvim.bak
mv ~/.cache/nvim ~/.cache/nvim.bak
```

### ✅ Клонирование

```bash
git clone --depth 1 https://github.com/posedonYT/AquaNvim.git ~/.config/nvim
nvim
```

Плагины, LSP-серверы и парсеры treesitter устанавливаются сами при первом запуске.

### 🧪 Попробовать, не трогая свой конфиг

```bash
git clone https://github.com/posedonYT/AquaNvim.git ~/.config/aquanvim
NVIM_APPNAME=aquanvim nvim
```


## 🧩 Extras

`Space X` (или `:AquaExtras`) открывает меню: `Enter` / `x` включает или выключает extra, затем
перезапустите Neovim — недостающие плагины установятся автоматически.

| Категория | Extras |
|---|---|
| lang | typescript · python · rust · go · c · bash · json · yaml · markdown · prisma · docker · tailwind · web (html/css) · sql (DBUI) |
| editor | harpoon · oil · multicursor |
| coding | surround · yanky |
| ui | noice · transparent · smear-cursor · colorizer |
| ai | claudecode (мост IDE: правки Claude показываются в Neovim как диффы) |
| dap | core (отладчик) |

Включены по умолчанию: `lang.typescript`, `lang.python`, `lang.rust`, `lang.prisma`, `lang.json`.

Из командной строки: `:AquaExtras enable lang.go`, `:AquaExtras disable lang.go`, `:AquaExtras list`.

**Собственные плагины** кладите в `lua/custom/plugins/*.lua` как обычные
[спецификации lazy.nvim](https://lazy.folke.io/spec). Пример смотрите в `example.lua` в этой папке.

## 🤖 Claude CLI

| Клавиши | Действие |
|---|---|
| `Space c` | Открыть/скрыть Claude справа, в **корне проекта** текущего файла |
| `Space a C` | То же, но в **папке текущего файла** |
| `Ctrl ,` | Скрыть/показать Claude (работает и внутри окна Claude) |
| `Space a f` | Добавить текущий файл в промпт (`@path`) |
| `Space a s` | (visual) Отправить выделение с путём и номерами строк |
| `Space a d` | Отправить диагностику текущей строки |
| `Space a c` / `Space a r` | `claude --continue` / `claude --resume` |
| `Space a p` | Выбрать запущенный экземпляр Claude |
| `Space a k` | Завершить Claude для этого проекта |

* У каждого проекта **свой экземпляр Claude**. Скрытие окна не останавливает процесс.
* Если курсор находится в Explorer или терминале, директория берётся из последнего редактируемого файла.
* Корень проекта = корень git → корень LSP → маркеры (`package.json`, `Cargo.toml`, `go.mod`, …) → папка файла.
* Файлы, изменённые Claude, перезагружаются автоматически.
* Включите extra `ai.claudecode`, и Claude подключится к Neovim как к IDE: предлагаемые правки открываются как диффы (`Space a y` — принять, `Space a n` — отклонить).
* Настройки: `vim.g.aqua_claude_cmd` (команда, например `{ "claude", "--model", "opus" }`), `vim.g.aqua_claude_width` (по умолчанию `0.4`).

## 🌊 Aqua AI — свой харнес для локальной нейросети

Чат с вашей моделью прямо в Neovim. Модель работает как агент: **сама читает, создаёт и правит файлы и папки,
ищет в интернете и редактирует Markdown по разделам** — но каждое изменение показывается вам для подтверждения.

| Клавиши | Действие |
|---|---|
| `Space o` | Открыть/скрыть чат-терминал справа, в **корне проекта** текущего файла |
| `Enter` | Отправить сообщение |
| `Shift Enter` | Новая строка в сообщении. Запасные варианты: `Alt Enter`, `Ctrl j` или `\` + `Enter` |
| `Esc` | Остановить ответ модели (очередь очищается) |
| `Esc` `Esc` | Режим Normal: прокрутка переписки, поиск, копирование, `gf` — открыть файл; `i` — снова ввод |
| `Ctrl c` | Остановить ответ; когда модель молчит — очистить ввод |
| `Ctrl h` / `Ctrl k` / `Ctrl w …` | Перейти в другое окно прямо из режима ввода (как в терминале Claude) |
| `Ctrl ,` · `q` (в Normal) · `:q` · `/exit` | Скрыть чат целиком — одним действием (разговор сохраняется) |
| `Space a o f` | Добавить текущий файл в сообщение (`@путь`) |
| `Space a o s` | (visual) Добавить выделение с путём и номерами строк |
| `Space a o d` | Добавить диагностику строки и попросить исправить |
| `Space a o m` / `Space a o p` | Выбрать модель / профиль |
| `Space a o n` | Новый чат |
| `Space a o y` | Режим YOLO — без подтверждений до конца сессии |
| `Space a o t` | Показать инструменты и права |
| `↑` / `↓`, `Ctrl p` / `Ctrl n` | Листать историю запросов |

В поле ввода работают команды `/new`, `/model [имя]`, `/profile`, `/yolo`, `/tools`, `/stop`, `/help`,
`/exit` — закрыть окно чата (`Tab` дополняет команду), а также `:AquaAI [toggle|new|model|profile|stop|yolo|tools|help]`.

### Чат — это терминал, как Claude Code

Aqua AI открывается **одним окном-терминалом**, как Claude: переписка и поле ввода в рамке нарисованы внутри него.
Поэтому окно ведёт себя как любой терминал Neovim: при входе в окно сразу можно печатать, `Ctrl h` / `Ctrl w l`
переключают окна, `Esc` `Esc` даёт обычный Normal для прокрутки и копирования, а `Ctrl ,`, `q` или `:q` прячут чат
целиком. Нет отдельного поля ввода, которое нужно закрывать само по себе. Файл, случайно открытый в окне чата
(`:e`, пикер), переносится в окно редактора.

Ответ модели оформлен как в Claude Code: `●` — текст модели (Markdown с заголовками, списками и подсветкой кода),
`❯` — ваши сообщения, инструменты — строкой с результатом под `⎿`. Внизу — статус со временем работы и рамка ввода.
Клавиши ввода как в терминале: `Ctrl a` / `Ctrl e` — начало / конец строки, `Ctrl b` / `Ctrl f` и `Alt b` / `Alt f` —
символ / слово, `Alt Backspace` — удалить слово, `Ctrl u` / `Ctrl k` — до начала / конца строки. Вставка из буфера
обмена многострочного текста не отправляет его.

### Чат и очередь сообщений

Отправив сообщение, вы **сразу можете писать следующее** — не нужно ждать ответа. Пока модель занята, новые сообщения
встают в очередь (видны в чате как `⏳ 1. …`, над полем ввода — счётчик) и попадают к модели на ближайшем шаге — в том числе
**между вызовами инструментов**, так что можно перенаправить агента на ходу. Очередь вмещает до 10 сообщений;
`Ctrl c` прерывает ответ и очищает очередь, `/new` начинает чат заново. Поле ввода растёт вместе с текстом.

> `Shift Enter` работает в терминалах с расширенным протоколом клавиатуры (kitty, Ghostty, WezTerm, iTerm2 с включённым
> «Report modifiers using CSI u» и др.). В остальных `Enter` и `Shift Enter` неразличимы — используйте `Ctrl j` или `\` + `Enter`.

### Подключение своей модели

Профиль задаётся в `lua/custom/options.lua`:

```lua
require("aqua.ai").setup({
  profiles = {
    default = {
      provider = "ollama",                 -- нативный API Ollama
      host = "http://localhost:11434",
      model = "gemma4:e4b",                -- не указали — выберете через :AquaAI model (запомнится)
      options = { num_ctx = 16384, temperature = 0.2 },   -- в Ollama по умолчанию контекст всего 4096!
    },
    lmstudio = { provider = "openai", host = "http://localhost:1234", model = "qwen2.5-coder-7b" },
    llamacpp = { provider = "openai", host = "http://localhost:8080", model = "local" },
    cloud    = { provider = "openai", host = "https://api.example.com", api_key_env = "MY_API_KEY", model = "..." },
  },
})
```

* `provider = "ollama"` — нативный API Ollama; `provider = "openai"` — **любой OpenAI-совместимый** сервер
  (LM Studio, llama.cpp, vLLM, Ollama `/v1` и т. д.).
* Переключение между профилями — `Space a o p`, выбор модели с сервера — `Space a o m`.
* Модель **должна поддерживать вызов инструментов** (tools / function calling). В Ollama это видно в `ollama show <модель>` →
  Capabilities: `tools`.

### Что умеет модель (инструменты)

| Инструмент | Категория | Что делает |
|---|---|---|
| `list_dir`, `read_file`, `find_files`, `grep` | чтение | Структура проекта, чтение файлов, поиск по имени и содержимому |
| `write_file`, `edit_file` | изменение | Создать/перезаписать файл; точечная замена текста |
| `create_dir`, `move_path` | изменение | Создать папку; переместить/переименовать |
| `delete_path` | удаление | Удалить в **корзину** (восстановимо, путь показывается в ответе) |
| `md_outline`, `md_read_section` | чтение | Структура Markdown и чтение раздела по заголовку |
| `md_write_section` | изменение | Заменить / дополнить / вставить в начало раздел (подразделы не затрагиваются); создаёт новые разделы и файлы |
| `web_search`, `web_fetch` | интернет | Поиск (DuckDuckGo без ключа, SearXNG, Brave) и загрузка страницы как читаемого текста |
| `open_in_editor` | чтение | Показать файл вам в редакторе |

Свой инструмент можно добавить из `lua/custom/options.lua`: `require("aqua.ai").register_tool({ name, description, parameters, category, run })`.

### Стек проекта и документация версий

Локальные модели (gemma, qwen, llama…) часто не знают свежих версий языков и библиотек и уверенно пишут устаревший код.
Поэтому Aqua AI **сам определяет стек проекта** и **изучает официальную документацию именно ваших версий**:

1. **Определение стека** — по манифестам, lock-файлам и установленным инструментам (до 2 уровней вложенности):

   | Экосистема | Что читается |
   |---|---|
   | Go | `go.mod` (go, toolchain, require/indirect, replace), `go.sum`, `go.work`, установленный `go` |
   | JS/TS | `package.json`, `package-lock.json` / `pnpm-lock.yaml` / `yarn.lock`, `.nvmrc`, `tsconfig.json`, установленный `node`, версия TypeScript |
   | Python | `pyproject.toml`, `requirements.txt`, `uv.lock` / `poetry.lock`, `.python-version`, установленный `python3` |
   | Rust | `Cargo.toml` (edition, rust-version), `Cargo.lock`, `rust-toolchain.toml`, установленный `rustc` |
   | C/C++ | `CMakeLists.txt`, `compile_commands.json`, `meson.build`, `Makefile` (`-std=…`), vcpkg/conan, компилятор (clang/gcc/Apple clang) |

   Несоответствия видны сразу: «установлен Go 1.26.1, а go.mod требует 1.27», «нет записи в go.sum», «Node старее требуемого».
2. **Авто-изучение** — перед первым запросом в проекте харнес скачивает **официальные заметки о выпуске** нужных версий
   (go.dev, docs.python.org, nodejs.org, typescriptlang.org, RELEASES.md Rust, cppreference, gcc.gnu.org, releases.llvm.org)
   и сохраняет их **один раз на версию** (кэш общий для всех проектов). В чате это видно как `📚 research Go 1.27 ✓`.
3. **Модель знает версии**: в системный промпт попадают стек (версии, зависимости с точными версиями, предупреждения),
   оглавление заметок о выпуске и правила — «твои знания могут быть старше; проверяй API этой версии; после правок — check_project».
4. **Инструменты модели**:
   * `project_stack` — подробный отчёт о стеке;
   * `lookup_docs` — заметки о выпуске версии (целиком раздел по `section`) или документация пакета **той версии, что в lock-файле**
     (npm, PyPI, crates.io; для Go-модулей — `go doc`);
   * `api_docs` — точный API установленной версии **локально**: `go doc` (stdlib и зависимости), `.d.ts` из `node_modules`;
   * `check_project` — проверка компилятором с подтверждением: `go build|vet|test ./...`, `cargo check|clippy|test --no-run`,
     `tsc --noEmit`, синтаксис Python, `cmake --build` / `-fsyntax-only`. Команду выбирает харнес, а не модель; ошибки
     компилятора возвращаются модели, и она их исправляет. Таймаут и `Ctrl c` останавливают проверку вместе с дочерними процессами.

| Команда | Действие |
|---|---|
| `Space a o S` · `:AquaAI stack` · `/stack` | Показать стек проекта и что уже изучено |
| `Space a o K` · `:AquaAI knowledge` · `/knowledge` | Сохранённые заметки (открываются как Markdown — работает режим чтения `Space m r`) |
| `Space a o R` · `:AquaAI research` · `/research` | Изучить версии заново |

Сетевые запросы к официальным источникам документации идут **без подтверждения** (категория прав `docs`, только домены из
списка); обычный `web_search` / `web_fetch` по-прежнему спрашивает. Настройки:

```lua
require("aqua.ai").setup({
  permissions = { docs = "allow", exec = "ask" },   -- docs: "ask" — спрашивать; "deny" — отключить
  knowledge = { auto = true, prompt_chars = 2500 }, -- auto = false — изучать только по запросу модели
  check = { timeout = 120 },                        -- секунд на check_project
})
```

### Безопасность

* **Подтверждения.** Чтение — свободно. Изменение, удаление и интернет требуют подтверждения: окно показывает **diff**;
  `y` — разрешить, `a` — разрешать эту категорию до конца сессии, `n` / `Esc` — отклонить (модель узнает об отказе).
  Если окно появилось, **пока вы печатаете**, обычные `y` / `a` / `Enter` игнорируются (чтобы случайная буква ничего не
  разрешила) — используйте `Ctrl y` / `Ctrl a`; через 2 секунды без набора окно снова реагирует на обычные клавиши.
  Отклонить можно всегда.
  Права настраиваются: `permissions = { read = "allow", write = "ask", delete = "ask", web = "ask" }` (`"deny"` скрывает инструмент от модели).
* **Песочница.** Файловые операции ограничены **корнем проекта**: `..`, абсолютные пути и симлинки наружу блокируются,
  запись в `.git` запрещена (`allow_outside_root = true` снимает ограничение).
* **Несохранённые правки.** Если файл открыт в Neovim с несохранёнными изменениями, модель не сможет его перезаписать.
* **Интернет.** Содержимое страниц — это данные, а не команды: модели запрещено им следовать. `web_fetch` к `localhost` и
  локальной сети заблокирован (`allow_private_web = true` разрешает).
* **Удаление** никогда не стирает данные безвозвратно: файлы переносятся в `~/.local/state/nvim/aqua_ai/trash/`.
* Произвольные команды оболочки модели **недоступны**: только `check_project` с фиксированным набором команд и подтверждением.

### Прочее

* История чата сохраняется отдельно для каждого проекта (`/new` — начать заново).
* Файл `AQUA.md` (или `AGENTS.md` / `CLAUDE.md`) в корне проекта подмешивается в системный промпт как проектные инструкции.
* Чат и Claude CLI не показываются одновременно: открытие одного прячет другого.
* Поиск: `search = { engine = "searxng", url = "http://localhost:8888" }` или `{ engine = "brave" }` (ключ в `BRAVE_API_KEY`).
* Лимиты: `max_steps` (шагов на запрос, 30), `context_chars` (бюджет истории; старые результаты инструментов сжимаются).

## 📖 Markdown: режим чтения

В `.md`-файле **`Space m r`** переключает **чтение ⇄ редактирование**.

В режиме чтения: текст в центрированной колонке (по умолчанию 100 символов) на чистом фоне, разметка скрыта — в том числе
на строке курсора, красивые заголовки, списки, чекбоксы, таблицы и блоки кода; **никаких диагностик** (линтер, LSP) и красной
орфографии; файл защищён от случайных правок. Строка подсказки сверху напоминает клавиши.

| Клавиши | Действие |
|---|---|
| `Space m r` | Включить / выключить режим чтения |
| `q` · `Esc` | Выйти из режима чтения |
| `i` `a` `o` `I` `A` `O` · `e` | Выйти и сразу редактировать (клавиша выполняется как обычно) |
| `]]` / `[[` | Следующий / предыдущий заголовок (заголовки внутри блоков кода пропускаются) |
| `Space m o` | Оглавление — выбор заголовка переносит к нему (работает и в обычном режиме) |
| `Space u m` | Выключить / включить рендер разметки в обычном режиме |

Все настройки возвращаются при выходе — даже если закрыть окно чтения командой `:q`. Ширина колонки:
`vim.g.aqua_reader = { width = 90 }` в `lua/custom/options.lua`. Замечания `markdownlint` (extra `lang.markdown`) в обычном режиме
не засоряют текст: остаются знаком на полях и в списке диагностик (`Space s d`).

## 💾 Сессии

Сессия автоматически сохраняется при выходе — по одной на **директорию + git-ветку**.
Explorer, Claude, терминалы и дашборд в неё не сохраняются, поэтому пустые «мёртвые» окна
не возвращаются. При смене проекта (`:cd`, `Space f p`) сначала сохраняется сессия предыдущего проекта.

| Клавиши | Действие |
|---|---|
| `Space q s` | Восстановить сессию для текущей директории |
| `Space q l` | Восстановить последнюю сессию |
| `Space q S` | Выбрать сессию |
| `Space q w` | Сохранить сейчас |
| `Space q d` | Не сохранять эту сессию при выходе |
| `Space q a` | Включить/выключить автовосстановление при запуске `nvim` без аргументов |

## ⌨️ Горячие клавиши

Нажмите `Space` и подождите: меню покажет все действия.

| Клавиши | Действие |
|---|---|
| `Space e` / `Space E` | Explorer (корень проекта / cwd) |
| `Space Space` | Поиск файлов |
| `Space /` | Grep по проекту |
| `Space ,` | Буферы |
| `Space f r` | Недавние файлы |
| `Space f p` | Проекты |
| `Space g g` | Lazygit |
| `Space l a` / `Space l r` / `Space l f` | Code action / переименование / форматирование |
| `Space b d` | Закрыть буфер |
| `Shift h` / `Shift l` | Предыдущий / следующий буфер |
| `Space - ` / `Space \|` | Разделить вниз / вправо |
| `Space u …` | Переключатели: перенос строк, диагностика, inlay hints, прозрачность, автоформат… |
| `Space n` | Новый файл |
| `Space m r` | (Markdown) режим чтения ⇄ редактирование |
| `Ctrl s` | Сохранить |
| `Ctrl a` | Выделить всё |
| `/` (visual) | Закомментировать / раскомментировать выделение |
| `Ctrl /` | Терминал |
| `s` | Flash-прыжок |

## ⚙️ Личные настройки

`lua/custom/options.lua` (необязательный файл) выполняется до загрузки плагинов: здесь удобно задавать `vim.g.aqua_*`
(команды и ширину Claude, автовосстановление сессий и т. д.), профиль модели Aqua AI и `vim.opt.*`. Плагины — в `lua/custom/plugins/`.

## 🎨 Тема

Палитра находится в `lua/aqua/theme/palette.lua`: abyss, deep, reef, turquoise, lagoon,
foam, coral, sand. Прозрачный фон: extra `ui.transparent` или `Space u B`.
